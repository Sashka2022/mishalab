# אטלס הסקרנות / Атлас любопытства

חידון סטטי למישה: **10 סבבים של 8 שאלות שונות**, בעברית וברוסית. הכרטיס הקיים `trivia` פותח את האטלס. ארבעת המשחקים האחרים ממשיכים לכלול 100 שלבים של 10 תרגילים.

## איפה עורכים

- **`questions.json`** — המקור לעריכה: שאלות, שלוש אפשרויות, תשובה נכונה, עובדה קצרה, מקורות ועשרת הסבבים.
- `answer` הוא המיקום של התשובה הנכונה במערך `options`, בספירה מ־0 עד 2. סדר האפשרויות קבוע ומאוזן; שינוי סדר אינו שאלה חדשה.
- לכל טקסט יש `he` ו־`ru`. `alt` מתאר את התמונה בלי שם התשובה; `accessiblePrompt` הוא נוסח חלופי שבודק ידע מקביל ואינו דורש ראייה.
- `rounds[].remember` מכיל **שני מזהי שאלות מאותו סבב**; העובדות שלהן מופיעות בסיכום.
- `source-catalog.json` ו־`source-review.json` מתעדים את המקורות ובדיקת התוכן. בדיקה מבנית אוטומטית אינה מחליפה בדיקת עובדות ותרגום לאחר עריכה.
- `atlas.js` — המסכים, בחירה/בדיקה/הבא, סיכום ושמירה; `atlas.css` — סגנונות תחומים למסך זה בלבד.

אחרי עריכה מריצים משורש המאגר:

```sh
node scripts/build-atlas.mjs
node tests/atlas.cjs
```

הבנייה בודקת 80 מזהים, שיוך יחיד לכל שאלה, 10×8, לפחות ארבעה תחומים בסבב, שלוש אפשרויות שונות בכל שפה, מקורות, תרגומים ומדיה מקומית. היא מעדכנת את `questions.js`, `media.js` ו־`CREDITS.md`; אין צורך בשרת יישומים או בתלות חדשה כדי להציג את המשחק.

## שמירה והקראה

מפתח ההתקדמות: **`misha-curiosity-atlas-v1`**, עם גרסת מאגר פנימית. התקדמות `data.learning.sessions.trivia` מהמשחק הקודם אינה מועתקת אליו. כל בחירה ותשובה נבדקת נשמרות מיד; רענון בכתובת `#atlas` מחזיר למסך שנשמר. אפשר לחזור לסבבים ולהמשיך סבב חלקי. ניקוד XP ניתן פעם אחת בלבד לכל שאלה שנענתה נכון, גם אחרי רענון או משחק חוזר.

השפה ו־Web Speech API משתמשים במנגנונים הקיימים של האפליקציה. ההקראה כוללת שאלה ואפשרויות, ואחרי בדיקה את התשובה הנכונה והעובדה. זמינות קולות עברית/רוסית בפועל תלויה בדפדפן ובמכשיר, כמו בשאר המשחקים. אין מעבר אוטומטי, גם אם הוא מופעל במשחקים האחרים. ייצוא ואיפוס הנתונים באזור המורה כוללים את האטלס.

## תמונות, מפות ורישיונות

הקבצים נמצאים ב־`assets/atlas/`. לכל קובץ רשומה ב־`media.json`: כתובת מקור, יוצר, רישיון, שינוי שבוצע ו־SHA-256. רשימת הקרדיטים המלאה זמינה גם במשחק וגם ב־[CREDITS.md](CREDITS.md). התצלומים אמיתיים; לא נוצרו תמונות חלופיות בבינה מלאכותית. קובצי CC BY-SA נשארים ברישיונות המתאימים, כולל הגרסאות המוקטנות.

המפות נגזרות מווקטורים מדויקים ומפושטים של Natural Earth, בנחלת הכלל. יש קבצים נפרדים בעברית וברוסית וגם מפת ישראל אנכית עם כתב גדול לטלפון. הגבולות הם תרשים גאוגרפי מפושט, ומקומות הערים נקבעו בקואורדינטות; המפה אינה מפת ניווט. לשחזור: הורידו את שני קובצי ה־GeoJSON שמקושרים ב־`scripts/build-atlas-maps.py`, ואז:

```sh
python3 scripts/build-atlas-maps.py countries.geojson lakes.geojson
node scripts/build-atlas.mjs
```

`fetch-atlas-media.py` ו־`import-atlas-media.py` מיועדים רק להכנת קובצי מדיה בזמן פיתוח; המשחק אינו פונה ל־Commons בזמן שימוש. הייבוא מקטין תצלומים באופן יחסי וממיר ל־WebP ללא חיתוך נוסף.

מסגרות ותחושת לחיצה הותאמו מרכיבי Cards ו־Buttons של PaperCSS. קוד המקור נבדק ב־commit `b341c1606fca5b3880307d779414f43a5ccbc9b6`; הודעת רישיון ISC המלאה נשמרה ב־`vendor/papercss/LICENSE.md`. לא נטען גיליון העיצוב הגלובלי של PaperCSS.

## בדיקות

`tests/atlas.cjs` מפעיל Chromium עם Playwright: סבב מלא בעברית וברוסית ברוחב 1440 ו־390, תשובות שגויות, סיכומים ושתי עובדות, רענון לפני ואחרי בדיקה, הקראה דרך המנגנון הקיים, שמירה נפרדת מהמשחק הישן, XP במשחק חוזר, כל 80 השאלות, נוסחים נגישים, טעינת מדיה, מסך דו־לשוני ברוחב 360 ופתיחת משחק הגפרורים. ההקראה נבדקת עם תחליף לקולות כדי לאמת את הטקסט והשפה, ללא תלות בקולות המותקנים בסביבת הבדיקה.

בדיקות נסיגה:

```sh
node tests/learning-games.cjs
node tests/learning-visual.cjs
```

הן בודקות 4,000 תרגילים קיימים, פתרונות, שמירה, מעבר אוטומטי במשחקים שבהם הוא קיים ו־72 צירופי משחק/שלב/שפה/גודל מסך.
